# Smart Agriculture IoT & Crop Protection

An IoT-powered smart agriculture and crop protection system with a modern React frontend dashboard.

## Overview

This project provides monitoring and management capabilities for smart agriculture, helping protect crops using IoT sensor data and automated controls.

## Project Structure

```
smart agriculture iot/
├── frontend/        # React + TypeScript + Vite frontend dashboard
└── README.md
```

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Frontend Setup

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
